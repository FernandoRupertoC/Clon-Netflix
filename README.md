# Equipo 3

# 🎬 Laboratorio Colaborativo: Clon de Plataforma Digital con Bootstrap

## 📌 Proyecto

**Clon visual de una plataforma digital utilizando HTML, CSS y Bootstrap.**

**Plataforma seleccionada:** Netflix

---

## 🎯 Objetivo

Desarrollar colaborativamente un clon visual de una plataforma digital aplicando:

* HTML
* CSS
* Bootstrap
* Git
* GitHub

El proyecto busca practicar la creación de interfaces **responsivas**, el uso de componentes de Bootstrap y el trabajo colaborativo mediante ramas y commits.

---

## 🛠️ Tecnologías utilizadas

* **HTML5**
* **CSS3**
* **Bootstrap 5**
* **Git**
* **GitHub**

---

## 🧩 Componentes Bootstrap utilizados

El proyecto incluye diferentes componentes de Bootstrap:

* Navbar
* Carousel
* Cards
* Buttons
* Grid System
* Forms
* Alerts
* Dropdowns

---

## 📱 Diseño responsivo

La interfaz está diseñada para adaptarse a diferentes tamaños de pantalla:

* 🖥️ Desktop
* 💻 Tablet
* 📱 Mobile

Se utiliza el **Grid System de Bootstrap** y clases responsivas para adaptar el contenido.

---

## 👥 Trabajo colaborativo

El desarrollo se realizó utilizando un repositorio compartido de GitHub.

Cada integrante participa mediante:

* Creación de una rama propia.
* Commits descriptivos.
* Desarrollo de diferentes secciones.
* Integración de cambios al proyecto.

### 🌿 Ejemplo de ramas

```text
main
├── feature/navbar
├── feature/cards
├── feature/carousel
├── feature/footer
└── feature/responsive
```

### 💾 Commits realizados

Los cambios realizados pueden consultarse directamente en el historial de commits del repositorio.
